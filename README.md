# Aqua Track — GitHub Pages

Versão preparada para hospedagem estática no GitHub Pages.

## Entrada do site

`index.html`

## Plataforma

`login.html` → `dashboard.html`

## Principais páginas

- `index.html` — página inicial
- `login.html` — login Firebase
- `cadastro.html` — cadastro Firebase
- `dashboard.html` — monitoramento em tempo real
- `historico.html` — histórico
- `alertas.html` — central de alertas
- `tratamento_ph.html` — guia de pH
- `tratamento_temperatura.html` — guia de temperatura
- `sobre.html` — sobre o projeto
- `contato.html` — contato compatível com GitHub Pages
- `404.html` — página não encontrada

## Firebase

Os arquivos abaixo foram preservados do TCCPHP original, sem alteração:

- `js/firebase-config.js`
- `js/firebase.js`
- `js/auth.js`
- `js/app.js`

## Publicação

No GitHub: `Settings → Pages → Deploy from a branch → main → / (root)`.

Leia `GUIA_DO_PROJETO.md` para o passo a passo detalhado, explicações para iniciantes e instruções de manutenção.
